# Sentence Analyzer and Prime Number Checker

## Project Description
This is a beginner-friendly Python project that analyzes a sentence and checks whether a given number is prime.

## Features
1. Counts the number of words in a sentence.
2. Finds the longest word.
3. Reverses the given sentence.
4. Checks whether a number is prime.

## Technologies Used
- Python 3

## Functions Used
- count_words()
- find_longest_word()
- reverse_sentence()
- is_prime()
- main()

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in the terminal.
4. Run the following command:

python main.py

5. Enter a sentence and a number when prompted.
